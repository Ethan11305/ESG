## 問題描述
- 目標：透過 API（LLM）自動讀取「ESG報告書.pdf」中的文字內容，並將敘述依據 ESG 三大面向分類為 E（環境）、S（社會）、G（治理）。
- 輸出格式：以 Markdown 條列（或表格）方式輸出，至少包含：
  - E：與碳排、能源、綠電、減碳、氣候策略、環境管理等相關的文字敘述
  - S：與勞動/人權、供應鏈、員工、社區、產品責任、職安等相關的文字敘述
  - G：與公司治理、董事會、內控、風險管理、反貪腐、資訊揭露等相關的文字敘述
- 需求細節：
  1. PDF 先被轉成可供分析的純文字（必要時以「每頁」或「章節」切塊）。
  2. 送入 LLM API 進行分類與摘要（避免逐字搬運，偏向「可引用的重點句/段落」）。
  3. 每一類至少產出 8–15 條重點（可依報告長度調整）。
  4. 每條重點建議保留「來源頁碼/段落標記」以便回查。
- 成功標準：
  - 能穩定從 PDF 產出 E/S/G 分類結果
  - 結果可讀、可追溯、可持續每天增量更新
